Google Sitemap Test

A minimal, controlled test site for verifying Google Search Console sitemap indexing, crawlability, and URL discovery.

  • ✓ sitemap.xml — standard XML sitemap at root
  • ✓ robots.txt — references sitemap, allows all bots
  • ✓ Canonical URL — set to GitHub Pages domain
  • ✓ Meta robots — index, follow
  • ✓ Open Graph — title, description, URL
  • ✓ Structured heading hierarchy — single H1
